# Asesor Fiscal IA

Asistente con inteligencia artificial para consultar documentación fiscal y contable de trabajadores autónomos.

## Cómo funciona

- Las respuestas se basan **exclusivamente** en la documentación oficial cargada.
- Si no hay información suficiente, el sistema **no inventará** una respuesta.
- Cada respuesta muestra las **fuentes utilizadas**: documento, página, sección y fragmento recuperado.

## Uso

1. Escribe tu pregunta sobre impuestos, cotizaciones o contabilidad.
2. (Opcional) Pulsa **"subir"** o **"cargar archivo"** para añadir documentación en PDF, TXT o Markdown.
3. Revisa la respuesta y sus fuentes.
